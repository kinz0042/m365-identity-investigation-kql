# Live dashboard demonstration

live-dashboard.mp4 is a 14-second silent recording assembled from 24 actual browser screenshots sampled during a live dashboard refresh. It shows the original two-row correlation, version-two validation totals and the conflicting source-record alert. The source logs are synthetic. The query engine and displayed results are live Azure Data Explorer.

recording-provenance.json records capture details. This is a short dashboard demonstration, not a full incident response session or evidence of activity in a real tenant.
